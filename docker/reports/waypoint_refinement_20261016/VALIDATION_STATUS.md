Waypoint 보간 기능 및 검증 결과 — 2026-10-16

구현과 ROS 설치본 반영을 완료했습니다. 실제 로봇에 명령을 보내지 않고 격리된 모의 장치와 저장 경로로 검증했습니다.

구현 내용

- Cartesian 구간은 직선 위치와 quaternion SLERP를 기준으로 IK 중간점을 만들고 JOINT 곡선으로 재현합니다. 허용 오차를 넘으면 Cartesian 분할 수를 늘리고 스무딩 강도를 낮춰 재시도합니다.
- JOINT 구간은 사용자가 입력한 중간점 수를 정확히 유지하고 관절값을 같은 비율로 나눕니다. 입력 범위는 구간당 0~255개입니다.
- 스무딩은 숫자·슬라이더·프리셋으로 0~100%를 입력합니다. 원본 지점과 대기는 보존하며 생성된 중간점에서 불필요하게 정지하지 않습니다. 실제 적용 강도는 진단 화면에 표시합니다.
- 보간을 켠 상태의 IK는 관절 제한 근처에서 여러 초기 자세로 다시 탐색합니다. 가능하면 5도(관절 가동 범위의 최대 5%) 여유를 확보합니다. 연속된 해를 찾기 어려우면 여유를 단계적으로 줄이되 최소 0.0001 rad를 요구합니다. 최종 해는 FK로 재검증합니다. 직접 입력한 JOINT 목표는 변경하지 않습니다.
- 보간 후 구간별 동일 시간과 전체 목표시간 배정을 지원합니다. 제외 구간·대기를 보존하고 실제 보간 planner로 재검증하며 실패하면 이전 설정으로 되돌립니다.
- 시간 배정 성공 직후 잘못된 변경 경고가 나타나는 브라우저 문제, 시작 직후 설정 전달과 상태 확인의 경합, 전송 노드 준비 중 제어권 전환, 준비 중 STOP이 취소되는 문제를 수정했습니다.
