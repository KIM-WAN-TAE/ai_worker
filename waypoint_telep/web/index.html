03 · CHECK & RUN

경로 확인

실행 시작 지점과 종료 지점을 고르면 현재 자세에서 해당 구간을 다시 계획합니다.

Cartesian 경로를 JOINT로 재현 · 보간과 스무딩

Cartesian 구간은 직선과 자세를 유지하도록 중간 관절점을 만듭니다. JOINT 구간도 지정한 수로 나눕니다. 원본 waypoint는 유지됩니다.

9를 입력하면 두 원본 지점 사이에 중간점 9개를 균등하게 만듭니다. JOINT 구간은 이 개수를 유지합니다. Cartesian 구간은 경로 오차를 줄이기 위해 필요한 경우에만 더 세분화합니다.

강도는 원본 구간 사이의 통과 속도를 얼마나 이어 줄지 정합니다. 0%는 원본 지점에서 정지하고 100%는 최대한 이어 줍니다. 원본 지점을 정확히 통과하며 대기 지점에서는 항상 정지합니다.
허용 오차를 넘으면 연결 강도를 낮춰 재시도하며 실제 적용 강도를 아래에 표시합니다. 이 보간을 적용한 뒤 목표시간 자동 배정을 사용할 수 있습니다. 기존 끝단 등속 설정은 먼저 해제해 주세요. 관절 제한 근처에서는 여유가 있는 다른 IK 해를 먼저 찾으며 기계적 경계에는 작은 여유를 남깁니다.
명령 샘플의 4배 밀도로 FK 오차를 검사합니다. 현재 자세에서 첫 지점까지의 정렬 이동은 오차 비교에서 제외합니다. 실제 로봇의 추종 오차와 충돌은 이 검사에 포함되지 않습니다.

목표시간 자동 배정

전체 목표시간은 첫 waypoint 도착부터 마지막 waypoint의 대기 종료까지입니다. 대기 시간과 제외 구간의 기존 시간을 보존하고, 남은 시간을 나머지 구간에 동일하게 배정합니다. 현재 자세에서 첫 waypoint로 정렬하는 시간은 별도입니다. 선택한 팔의 목록 전체를 정순으로 계산합니다.

225번 제외는 224→225 이동을 보존한다는 뜻입니다. 적용 시 기존 끝단 등속 설정을 대체하며 거리가 다르면 속도도 달라집니다. 전체 목표시간은 반드시 입력해야 하며, 허용 범위나 샘플 변화량 한도를 통과하지 못하면 기존 설정을 유지합니다. 구간당 시간 모드에서만 빈칸을 자동 계산합니다. 검증은 로봇을 움직이지 않으며 관절 상태 입력이 없으면 첫 waypoint를 시작 자세로 사용합니다.

시간 배정 후 검증 결과가 여기에 표시됩니다.
