        목표시간 자동 배정 · 끝단 속도 균일화
        

          
          
          
          
          
          
        

        
전체 목표시간 모드는 실제 끝단 이동 거리를 기준으로 속도를 고르게 맞춥니다. JOINT 연속 통과와 ‘부드럽게 연결’ 모두 지원하며, 검증된 경로 모양과 구간별 속도 배율은 유지하고 시간축만 조절합니다. 출발·정지, 방향 전환과 관절 제한 때문에 필요한 곳에서 감속합니다.

        
전체 시간은 첫 waypoint 도착부터 마지막 지점의 대기 종료까지이며, 현재 자세에서 첫 지점으로 정렬하는 시간은 별도입니다. 대기와 제외 구간의 기존 시간을 유지합니다. 제외 번호는 하나의 연속 범위로 지정하세요. 225번 제외는 224→225 이동을 뜻합니다. 목표시간을 맞출 수 없으면 기존 설정을 유지합니다. ‘구간당 동일 시간’은 거리와 무관하게 시간을 나누는 별도 모드입니다. 계산·검증은 로봇을 움직이지 않습니다.

        
시간 배정 후 검증 결과가 여기에 표시됩니다.
