구간을 골라 곡선 경로 만들기

원하는 구간마다 곡선 또는 직선을 선택하세요. 중간점과 스무딩은 자동으로 계산합니다.

1

기준 경로 선택

기존 파일을 불러오거나 Teleop에 있는 경로를 사용하세요.

2

구간과 연결 방식 선택

끝점을 고르고 곡선 또는 직선을 선택하세요. 구간은 자유롭게 추가할 수 있습니다.

기준 경로를 먼저 선택해 주세요.

각 구간 끝점의 위치·자세·그리퍼·대기시간을 유지합니다. 선택한 구간만 새 경로로 저장합니다.

3

생성 및 검사

곡선 정도가 0이면 직선이 됩니다. 스무딩은 별도로 자동 적용합니다.

고급 설정 같은 설정과 시드로 같은 결과를 만듭니다. 시작점 위치·방향의 범위는 첫 시작점 옵션에서 정합니다.

기준 경로를 선택해 주세요.

경로 미리보기

회색은 직선 기준, 파랑은 곡선, 초록은 직선 삽입 구간입니다.

생성 전에는 예상 모양을 표시합니다. 생성 후에는 검사한 관절 경로의 FK 결과를 표시합니다.

검사 완료

원래 Teleop 목록은 유지됩니다. 저장한 Waypoint JSON을 Teleop에서 불러오면 됩니다.
